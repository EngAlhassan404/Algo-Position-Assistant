# Algo Position Assistant

## نبذة عن الاكسبرت

**Algo Position Assistant** هو مساعد آلي لإدارة المراكز في منصة MetaTrader 5. يوفر لوحة تحكم تفاعلية داخل الرسم البياني لتنفيذ أوامر شراء وبيع بنقرة واحدة، إغلاق المراكز المؤهلة، وتفعيل أو إيقاف إدارة وقف الخسارة المتحرك.

تاريخ إنشاء الاكسبرت والمستودع: **12 نوفمبر 2026**  
المطور: **المهندس الحسن علي باحبه**

## الوظائف الرئيسية

- تنفيذ شراء وبيع بنقرة واحدة مع تحديد حجم العقد من اللوحة.
- إغلاق المراكز على الرمز الحالي أو على مستوى الحساب.
- إدارة المراكز حسب الرمز الحالي أو جميع الرموز.
- فلترة المراكز اختياريًا بواسطة `Magic Number`.
- وقف خسارة متحرك يعتمد على SuperTrend.
- احترام `Stops Level` و`Freeze Level` الخاصين بالوسيط.
- تحريك وقف الخسارة في اتجاه تشديد الحماية فقط، دون إعادته للخلف.
- رسم خطوط SuperTrend المؤكدة على الرسم البياني.
- لوحة قابلة للسحب والتصغير داخل حدود الرسم البياني.

## الوضع الحالي وإمكانية التوسعة

الإصدار الحالي يعتمد على **إدارة SuperTrend فقط** كاستراتيجية وقف خسارة متحرك. تم بناء إدارة المراكز بمعمارية تعتمد على الكلاسات:

- `CPositionManagerBase`: واجهة مجردة مشتركة لأي مدير مراكز جديد.
- `CSuperTrendPositionManager`: التطبيق الحالي لإدارة وقف الخسارة بواسطة SuperTrend.
- `CSymbolSuperTrendPool`: يحتفظ بمحرك SuperTrend مستقل لكل رمز عند استخدام نطاق إدارة الحساب.
- `CSuperTrendEngine`: حساب SuperTrend باستخدام ATR وإرجاع مستوى وقف الخسارة المناسب للشراء أو البيع.

يمكن إضافة أي نوع آخر من الوقف المتحرك، مثل ATR Trailing أو Break-even أو Parabolic SAR، عبر إنشاء كلاس يرث من `CPositionManagerBase` ثم ربطه بالوضع الجديد في `ENUM_MGMT_MODE`. هذا يجعل إضافة استراتيجيات إدارة مستقبلية ممكنة دون إعادة كتابة حلقة إدارة المراكز الأساسية.

يوجد أيضًا الكلاس `CPositionRisk` في:

`Include/CPositionRisk.mqh`

وهو مساعد مستقل لحساب حجم العقد بناءً على نسبة المخاطرة، وسعر الدخول، وسعر وقف الخسارة، مع مراعاة حدود وخطوة حجم العقد لدى الوسيط. يمكن ربطه لاحقًا بأزرار التداول أو بأي مدير مراكز جديد.

## الإعدادات

### إعدادات محرك SuperTrend

| الإعداد | الوصف | الافتراضي |
|---|---|---:|
| `InpSTTimeframe` | الإطار الزمني لحساب SuperTrend | `PERIOD_CURRENT` |
| `InpSTAtrPeriod` | فترة ATR المستخدمة في الحساب | `10` |
| `InpSTMultiplier` | معامل ATR لـ SuperTrend | `3.0` |

### وقف الخسارة المتحرك وحماية الوسيط

| الإعداد | الوصف | الافتراضي |
|---|---|---:|
| `InpSTTrailBar` | الاعتماد على الشمعة الحالية أو آخر شمعة مغلقة عند تحديد وقف الخسارة | الحالية |
| `InpInitialTrailState` | حالة التريلينغ عند تشغيل الاكسبرت | `false` |
| `InpInitialScope` | إدارة رمز الرسم الحالي أو كل مراكز الحساب | الرمز الحالي |
| `InpMagicFilter` | إدارة مراكز Magic Number محدد؛ القيمة `0` تعني قبول جميع المراكز | `0` |
| `InpMinStepPoints` | أقل مسافة لتحديث وقف الخسارة بالنقاط | `1` |
| `InpExtraStopBuffer` | هامش إضافي فوق مسافة توقف الوسيط بالنقاط | `0` |

### افتراضيات التداول بنقرة واحدة

| الإعداد | الوصف | الافتراضي |
|---|---|---:|
| `InpDefaultLot` | حجم العقد الابتدائي، ويُضبط تلقائيًا ضمن حدود الوسيط | `0.01` |
| `InpSlippagePoints` | أقصى انحراف مسموح بالنقاط | `20` |

### خطوط SuperTrend

| الإعداد | الوصف | الافتراضي |
|---|---|---:|
| `InpShowSTLines` | إظهار خطوط SuperTrend على الرسم | `true` |
| `InpSTDrawBars` | عدد الشموع التاريخية المرسومة | `250` |
| `InpSTUpColor` | لون الاتجاه الصاعد | `clrLimeGreen` |
| `InpSTDownColor` | لون الاتجاه الهابط | `clrRed` |
| `InpSTLineWidth` | عرض الخط | `2` |

### موضع لوحة التحكم

| الإعداد | الوصف | الافتراضي |
|---|---|---:|
| `InpPanelX` | الموضع الأفقي الأولي للوحة بالبكسل | `20` |
| `InpPanelY` | الموضع الرأسي الأولي للوحة بالبكسل | `35` |

## طريقة عمل SuperTrend

عند تفعيل الإدارة:

- صفقة الشراء: يحاول الاكسبرت رفع وقف الخسارة إلى نطاق SuperTrend السفلي فقط.
- صفقة البيع: يحاول الاكسبرت خفض وقف الخسارة إلى نطاق SuperTrend العلوي فقط.
- لا يتم تحديث الوقف إذا كان قريبًا من سعر السوق وفق قيود `Stops Level` أو `Freeze Level`.
- يمكن استخدام الشمعة الحالية للاستجابة الأسرع أو آخر شمعة مغلقة لتقليل تغيرات الإشارة أثناء تكون الشمعة.

## هيكل المشروع

```text
Expert/
  Algo Position Assistant.mq5   # الاكسبرت واللوحة ومنطق إدارة المراكز
  Algo Position Assistant.ex5   # ملف مترجم موجود في المشروع
Include/
  CSuperTrendEngine.mqh         # محرك حساب SuperTrend
  CPositionRisk.mqh              # مساعد حساب المخاطرة وحجم العقد
```

## التثبيت

1. انسخ مجلد `Expert` إلى مجلد `MQL5/Experts`.
2. انسخ مجلد `Include` إلى مجلد `MQL5/Include`.
3. افتح `Algo Position Assistant.mq5` في MetaEditor ثم قم بالترجمة.
4. أضف الاكسبرت إلى الرسم البياني واضبط الإعدادات قبل تفعيل التداول.

## تنبيه المخاطر

هذا الاكسبرت أداة تقنية لإدارة المراكز وليس نظامًا للتنبؤ بالسوق أو ضمان الأرباح. يجب اختباره على حساب تجريبي، والتحقق من إعدادات الوسيط، وفهم سلوك SuperTrend وقيود وقف الخسارة قبل استخدامه على حساب حقيقي.
